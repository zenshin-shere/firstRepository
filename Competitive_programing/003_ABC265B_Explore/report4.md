## 問題文

高橋君はゲームの中で洞窟を探索しています。

洞窟は $N$ 個の部屋が一列に並んだ構造であり、入り口から順に部屋 $1,2,\ldots,N$ と番号がついています。

最初、高橋君は部屋 $1$ におり、持ち時間は $T$ です。

各 $1 \leq i \leq N-1$ について、持ち時間を $A_i$ 消費することで、部屋 $i$ から部屋 $i+1$ へ移動することができます。これ以外に部屋を移動する方法はありません。また、持ち時間が $0$ 以下になるような移動は行うことができません。

洞窟内には $M$ 個のボーナス部屋があります。$i$ 番目のボーナス部屋は部屋 $X_i$ であり、この部屋に到達すると持ち時間が $Y_i$ 増加します。

高橋君は部屋 $N$ にたどりつくことができますか？

---

## 制約

- $2 \leq N \leq 10^5$
- $0 \leq M \leq N-2$
- $1 \leq T \leq 10^9$
- $1 \leq A_i \leq 10^9$
- $1 < X_1 < \ldots < X_M < N$
- $1 \leq Y_i \leq 10^9$
- 入力に含まれる値は全て整数

---

## 入力

入力は以下の形式で標準入力から与えられます。

```text
N M T
A_1 A_2 ... A_{N-1}
X_1 Y_1
X_2 Y_2
...
X_M Y_M
```

---

## 出力

高橋君が部屋 $N$ にたどりつくことができるなら `Yes` を、できないなら `No` を出力してください。

---

## 入出力例

### 入力例 1

```text
4 1 10
5 7 5
2 10
```

### 出力例 1

```text
Yes
```

> 高橋君は最初、部屋 $1$ にいて持ち時間は $10$ です。
>
> - 持ち時間を $5$ 消費して部屋 $2$ に移動します。持ち時間は $5$ になります。その後、持ち時間が $10$ 増え、$15$ になります。
> - 持ち時間を $7$ 消費して部屋 $3$ に移動します。持ち時間は $8$ になります。
> - 持ち時間を $5$ 消費して部屋 $4$ に移動します。持ち時間は $3$ になります。

### 出力例 2

# コード
``` cpp
#include <bits/stdc++.h>
using namespace std;
#define rep(i,n)for (int i =0 ;i<(n); i++)

int main() {
	int n, m;
	long long t;
	cin>> n>>m>>t;
	vector<int> a(n-1);
	rep(i,n-1) cin >> a[i];

	vector<int> b(n);
	rep(i,m){
		int x,y;
		cin >> x >> y;
		b[x-1]=y;
	}

	rep(i,n-1){
		t += b[i];
		t -= a[i];
		if(t<=0) {
			cout << "No"<<endl;
			return 0;
		}
	}
	cout <<"Yes"<<endl;
	return 0;
}
```
# 解説

高橋君が部屋 $N$ に到達できるかを判定する問題。  

色々変数があるが一つ一つ確実に機械的に処理していけば解ける。  
ボーナス部屋の情報は、配列などを使って管理するとよい。
